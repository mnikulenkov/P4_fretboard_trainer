P4 Fretboard Trainer Guide

🎯 Game Objective

Train your ability to quickly identify notes and chord shapes on the guitar fretboard through regular practice.

🎮 How to Play

  1. A note, chord, or interval-sequence pattern will be highlighted on the fretboard
  2. Choose the correct name from the answer buttons below
  3. Correct answers increase your score; incorrect ones let you try again

⚙️ Game Modes & Settings

Click the ⚙️ button in the top bar to access settings:

  • Notes Mode: Practice identifying individual notes
  • Interval Mode: Two notes are shown — the red one is the root, the green one is the second note. Name the interval counted up from the root within one octave: a note below the root answers as its inversion (a 3rd below = M6), and an interval beyond an octave answers as its simple equivalent (a 9th = M2). The Direction checkboxes choose whether the second note sounds above (regular) or below (inversions) the root; Intervals picks which ones you practice; Max string span (up/down) sets how far the second note may sit from the root's string — the same interval can be fingered on 1, 2, 3 or more strings
  • Chord Mode: A chord voicing is shown — the red note is the root, the green notes are the other chord tones. Name the chord as root + type (e.g. A7, Cm7, F#maj7); answers are unambiguous, so spelling must match exactly (as shown in the reveal). The shapes are movable P4 voicings: each works at any fret in the range (chords never use open strings) and on any string group where it fits — root position and inversions are all in play. Chord types picks the families you practice; Inversions picks which chord tone may sit in the bass (root position only, or specific inversions). Some voicings omit a degree (e.g. 9ths without the 5th, the first-inversion 9th without the b7)
  • Interval Sequence Mode: Identify an arpeggio or scale from a pattern of connected one-octave shapes — a symmetry of all-fourths tuning: the pattern is built from random applicatures of the sequence chained root → octave → next root, so the same shape works anywhere on the fretboard
  • Triads Mode (legacy): The original 3-string triad quiz on shapes computed on the fly — kept for old habits; prefer Chord Mode, which drills real P4 voicings
  • 🔴 Interval Sequence tip: Red notes are the root (P1) and the octaves (P8) — the tonal center; all other notes are green. The answer options are deliberately misleading (close scales and modes are included), so pay attention to which degrees are present and where the root sits
  • Handbook: the 📖 button (or H) opens the reference guide — the P4 tuning, intervals, all 66 chord voicings, every scale & arpeggio shape and the mnemonics, rendered for your current instrument. The long sections carry a chip bar (it stays pinned while you scroll) to jump straight to any chord family, interval or scale group, plus a name filter for the 146 shapes; it reopens on the last section you read. Click any diagram to hear it
  • Fret Range: Set minimum and maximum frets to practice
  • Tuning: All-fourths only — set the lowest string's note/octave and the number of strings (4 to 8); every higher string is a perfect fourth above the previous one
  • Strings: Choose which strings to include in practice
  • Note Types: Select which notes to practice (naturals, sharps, naturals half-tones, etc.)
  • Mnemonics: Note drills built on named shape mnemonics — currently one, the half-step-down C major scale: spell a highlighted shape with the on-screen note buttons (GFE, CBA…), name the note marked red inside it, or pick the neighbouring shape's pattern. Unlock it by tuning to all fourths a half step down (lowest string D# on 4/6 strings, A# on 5/7); the Guide button in settings opens the Handbook's Mnemonics section, which explains the full system with a visual scheme
  • Triad Types: Practice major, minor, diminished, or augmented triads
  • Sequences: Choose which arpeggios and scales to practice, and optionally label the fretboard with the notes' intervals (P1, m3, P5…) while answering

The P4 tuning

🎸 What all-fourths is

Every pair of adjacent strings is a perfect fourth (5 semitones) apart. Standard guitar tuning breaks this pattern once — its 2nd and 3rd strings are a major third apart — which is why shapes change when they cross strings there. All-fourths removes that exception, so the fretboard becomes completely uniform.

📐 The symmetry

  • Along the neck: any shape slides freely up and down — everything just shifts chromatically
  • Across the strings: one string toward the floor = a fourth higher, so the same shape on the same frets works on every string group
  • These two symmetries are why one diagram per chord shape is enough, and why the trainer can place every pattern anywhere on the fretboard

🗺️ Your instrument (live — changes with the tuning settings)

📏 How intervals are named

Intervals are always counted up from the red root, within one octave: a note below the root answers as its inversion (a 3rd below = M6), and an interval beyond an octave answers as its simple equivalent (a 9th = M2).

🪜 The P4 ladder

Each interval can be fingered on one string or spread across several — moving the second note one string up (toward the higher strings) lets it drop 5 frets. A P4 is the same fret on the next string; a P8 is two strings up at fret +2; the tritone sits in between. Use the options to pick which intervals to show, the string range a fingering may span (vertical) and the fret window it must fit in (horizontal — the root sits at the window's start, and fingerings too wide for it are hidden). The chips below jump straight to an interval; click a diagram to hear it.

🎶 Movable P4 voicings

These are all 66 chord voicings (22 chord types), shown as pure movable shapes: the red R marks the root's slot inside the shape — whatever note that slot lands on as you move the shape is the root of the chord you get — and the green dots are the other chord tones. × marks a muted string inside the shape. The voicings never use open strings: each works at any fret and on any string group where it fits — exactly what the Chords quiz trains. A no 5-style badge marks degrees a voicing leaves out. The caption lists two spellings for each family: the chord tones counted from the root (a major triad is 1-3-5) and the intervals stacked between the notes (that triad is M3 + m3). The chips below jump straight to any chord family; click a diagram to hear it.

🎹 One-octave shapes

Every arpeggio and scale is shown as its narrowest one-octave applicature on your instrument — the building block the Interval Sequence quiz chains root → octave → next root across the fretboard. Red pills mark the root and the octave (P1/P8); the pills show scale degrees, spelled from the interval names (#IV vs bV — spelling matters). Tiers mirror the quiz defaults: tier 1 is on by default, tiers 2-3 opt in. Use the chips to jump to a group and the filter box to narrow the list by name; click a diagram to hear it ascending.

🧩 What a mnemonic is

A mnemonic is a named system that chunks part of the fretboard into fixed, nameable shapes — know the shapes and any note they cover names itself. Each system gets its own subsection here, and the Note mode's Mnemonics submenu offers the same systems as checkboxes. So far there is one.

Half-step-down C major scale

🎸 The tuning

This mnemonic works on all-fourths instruments tuned a half step down: 6-string with the lowest string D# (open D# G# C# F# B E, low → high), 7-string with the lowest string A# (open A# D# G# C# F# B E), basses likewise. With that tuning, fret 1 of every string is a natural note — on a 6-string, from the highest string down: F C G D A E; a 7-string adds B at the bottom.

🗺️ Reading the map

  • The map spans one octave, open string → 12th fret; the drills read it from fret 1
  • The C-major naturals of every string group into 3 shapes; between neighbouring shapes exactly one fret is skipped — the sharps
  • The dimmed dashed column at the left is the open string — the previous octave's end of the cycle, not a fourth shape. On the top F and C strings it is a natural (E, B — the last shape's top note an octave down) and meets fret 1 with no skipped fret (E–F and B–C are half steps); on the other strings it is itself one of the skipped sharps
  • Shape names read from the highest note down: GFE = G, F, E

📐 Shape types (named by the first interval — the second between the first two notes)

  • x = 1 — single note
  • xx = 2m / x_x = 2b — two notes a minor (half step) / big (whole step) second apart
  • xx_x = 3m / x_xx = 3b — three notes, minor / big first second

Every E–F and B–C pair gets absorbed into a 3-note shape, so xx (2m) never occurs among the string shapes.

🧠 The system

Each string always carries its fixed group of 3 shapes (below: your current instrument). Learn those groups and any natural note on the fretboard names itself — the shape tells you the letters, the position tells you which is which.

Legend: tinted cells = shape notes · # = sharp skipped inside a shape · · = sharp skipped between shapes · the dashed leftmost column = the open string (the previous octave's ghost)

🎯 The drills

  • Name the shape — a shape is highlighted; tap its letters with the on-screen note buttons. The letters name the shape — type them in any order; the canonical name reads from the highest note down (GFE, CBA, ED…)
  • Name the red note — one note of the highlighted shape is red; name it
  • Neighbour shape — a shape is highlighted; pick the pattern of the shape to its left or right (left = toward the nut)

🎼 What the Progression Lab is

Type a chord progression as degrees — functions, no absolute roots — pick a base root, and the lab ranks the scales and arpeggios to play over each chord. The ranking is driven by how the scale's stable tones fit the current chord and resolve into the next one, every suggestion explains itself, and chords + scale play together so you can hear the fit. Open it with the 🎼 toolbar button or the L key.

✍️ Writing degrees

  • Degrees always count in the major scale on the base root, even in minor keys — one rule, no case conventions to memorize. A minor is simply Im7 bIIImaj7 bVImaj7 bVII7
  • An uppercase numeral + the same quality suffixes the Chords mode uses: Imaj7 IIm7 V7 VIIm7b5. A bare numeral (IV) is a major triad; case never carries meaning
  • b/# before the numeral lowers/raises that degree: bVIImaj7, #IVm7b5
  • V7/II is a secondary chord: the numerator counts from the target (here A7, dominant of Dm7). One nesting level: V7/V/V is rejected
  • . repeats the previous chord (vamps, 12-bar forms); | draws a bar line and is visual only
  • *N after a chord sets its length in bars — I7*4 IV7*2 — fractional allowed (*0.5 for fast changes); unset chords take the transport's bars-per-chord setting (default 2)
  • Typing aids: ♭ ♯ Δ ø ° all fold to ASCII equivalents; the editor autocompletes tokens as you type (↑↓ Enter); hovering a chip dissects the token and lists alternate spellings of the same chord

⚖️ How suggestions are ranked

Every chord tone and scale degree carries a pre-researched stability value — how much it sounds at rest to the ear — from listener-rating experiments (Krumhansl–Kessler probe-tone profiles) and music-theoretic models of consonance (Lerdahl's tonal pitch space, Parncutt's root-support weights). These live in a static atlas inside the lab; nothing about stability is computed from intervals at runtime. Three terms combine them:

  • Fit — each overlapping tone counts with both stabilities multiplied (scale's × chord's), normalized by the chord's total stability mass
  • Resolution — the scale's non-chord tones resolving by half or whole step into the next chord's stable tones (Lerdahl's melodic-attraction shape: target stability × closeness)
  • Penalty — avoid notes (a half step above a chord tone) and the ♭9-over-root clash, both classic voice-leading no-gos

The model re-derives standard pedagogy from the data alone — dorian over iim7 (aeolian's ♭6 is an avoid note), lydian over Imaj7 (ionian's 4th is), mixolydian or lydian dominant over V7 — which is the best evidence the atlas is honest. Cards are grouped by family (heptatonic / pentatonic / arpeggio) because a subset scale that contains the whole chord always scores a "safe" high fit.

🪜 Scale plans — several scales inside one chord

  • Any chord can carry a plan: an ordered list of scales partitioning its span — a four-bar Imaj7*4 might run ionian → lydian → ionian. The plan strip shows segments sized by duration: drag a boundary to resize (½-bar snap), tap the ▾ for presets, and use ＋ to split the widest segment
  • The same stability rules apply between scales: each card's in meter shows how the previous scale resolves into it, and the resolution line names its target segment. The exit into the next chord resolves into that chord's first segment when it has one
  • The 🔗/⛓ between chips toggles whether a boundary participates in ranking (toggling re-ranks both sides); the flow checkbox mutes all internal boundaries at once; the safety ↔ color slider reshapes the weights (its middle is the default research weighting)
  • ✨ auto builds plans — ranked, rising tension (build over a vamp), out-and-back, or max contrast — for the selected chord or, via all chords, the whole progression at once
  • what changes draws dashed ghost pills for the tones the next segment introduces (see F♯ one fret above your F before you play it); sound link plays each boundary's strongest moving resolver as a grace-dyad instead of the new scale's first note — hear the 4 fall to the 3
  • The tension strip under the chord chips shows every segment's color level across the whole progression (width = duration, height = tension); click a bar to jump there

🎛️ Playing it

  • Presets — the dropdown loads ii–V–Is, the backdoor cadence, Andalusian, both 12-bar blues forms, rhythm changes, a Coltrane cycle and more — plus a Jazz standards group with 79 real tunes (All of Me to Giant Steps); picking one loads its changes and its own key, so Autumn Leaves opens in G
  • Transport — loops the progression at your BPM and bars-per-chord: each chord is strummed while the selected scale plays as a phrase that spans the chord exactly — it enters near where the previous chord's line left off, arches up (stable tones as quarter notes, color tones as eighths) and lands on the tone that best resolves into the next chord, held so it rings across the barline. Space toggles it, chip clicks jump, count-in optional, swing gives the line the relaxed triplet feel, and the feel selector re-grids the line as straight 8ths, triplets or 16ths (double-time; structural tones still anchor)
  • Share links — 🔗 copies a URL like #lab=C@IIm7,V7,Imaj7; plans ride along as compact suffixes (Imaj7*4[ionian*2;lydian;ionian]), so opening it restores the progression, root and scale plans (the hash never leaves the browser)
